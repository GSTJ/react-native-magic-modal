## Imports

Every public value and type is available from the package root:

```tsx
import {
  MagicModalHideReason,
  MagicModalPortal,
  magicModal,
  useMagicModal,
  type Direction,
  type HideReturn,
  type ModalChildren,
  type ModalProps,
  type NewConfigProps,
} from "magic-modal";
```

<Callout type="info">
  The configuration table is generated directly from the TypeScript source
  during the docs build. Function pages are curated because generated
  declarations do not communicate async lifecycle or cancellation semantics
  well.
</Callout>
