## Before opening an issue

Include the Magic Modal, React Native, Expo, Gesture Handler, Reanimated, and Worklets versions used
by the affected target. For gesture or layering bugs, include a small reproduction.

Run `npx expo-doctor` in Expo projects and confirm that
[`MagicModalPortal`](/docs/reference/magic-modal-portal) is mounted exactly once before reporting a
setup problem.
