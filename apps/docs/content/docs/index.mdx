React Native Magic Modal turns a modal interaction into a typed async result. Mount one
`MagicModalPortal` near the application root. Call `show()` from an event, effect, service, or any
other async flow.

```tsx
const result = await magicModal.show<ConfirmationResult>(ConfirmationModal, {
  accessibilityLabel: "Confirm purchase",
}).promise;

if (
  result.reason === MagicModalHideReason.INTENTIONAL_HIDE &&
  result.data.confirmed
) {
  completePurchase();
}
```

## The mental model

1. [`MagicModalPortal`](./reference/magic-modal-portal) owns the modal stack. Mount it once.
2. [`magicModal.show`](./reference/magic-modal) pushes one entry and returns its ID and promise.
3. [`useMagicModal().hide`](./reference/use-magic-modal) closes that entry with typed data.
4. The promise resolves to [`HideReturn<T>`](./reference/hide-results), including the close reason.

Every `show()` call creates an independent stack entry. Opening another modal keeps the earlier
entry and its promise in place.

<Callout type="info" title="Application modals">
  Magic Modal handles discrete interactions and async decisions. Snap points and
  nested bottom-sheet scrolling are outside its scope.
</Callout>
